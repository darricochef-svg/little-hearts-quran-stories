# Upload and publishing checklist
- [ ] Final MP4 plays to the end on a phone
- [ ] Arabic pronunciation reviewed by a fluent speaker
- [ ] Quranic details reviewed against trusted Quran/tafsir sources
- [ ] English subtitles synchronized and reviewed
- [ ] Thumbnail, title and description accurately represent the video
- [ ] Asset/audio licenses permit intended public/commercial use
- [ ] Correct child-directed audience setting selected in YouTube Studio
- [ ] Upload privately/unlisted for final review
- [ ] Final owner approval for date and public visibility
- [ ] If scheduling, confirm date, time and timezone
- [ ] Record video ID, URL, publication time and result in publishing-calendar.csv

## Automation notes
The official YouTube upload API requires a Google Cloud project, YouTube Data API v3 enabled, and user OAuth authorization with upload scope. Never paste passwords, OAuth client secrets, API keys or browser cookies into chat. Keep credentials local and secure. Until authenticated automation has been set up and tested, use YouTube Studio's native scheduling feature.
